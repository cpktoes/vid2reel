<objective>
Make normalize polite and safe: a file that is too big or cannot be read gets one plain sentence and the others carry on (NORM-06, D-19 to D-22); letters and the manifest stay complete (NORM-05); originals are provably never written to (NORM-07, D-05); and the run refuses to start if the computer's FFmpeg lacks a piece doctor lists (NORM-08, D-06).

Plain English for the user: if she sends a file that is too large or is not a clip or photo, the chat will be able to say exactly which one ("the second file, IMG_4423.MOV, could not be read") while the rest still get converted. Her original files are checked byte for byte to be untouched. And if the sandbox's FFmpeg ever lacks a part, the command says so in one sentence instead of making broken copies.

Purpose: nothing she sends can stop the others, and nothing is ever lost or changed.
Output: refusal logic, sentences, the start-up check and their tests.
</objective>

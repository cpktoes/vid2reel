## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest.json to look | the manifest's file names and numbers are read as data; a hand-edited manifest is untrusted |
| working copy to ffmpeg | untrusted bytes cross into FFmpeg; the path crosses into subprocess arguments |
| look to the work folder | the only place look writes |
| look.json to the chat's Claude | look.json is read by a model, so text in it could be mistaken for an instruction |

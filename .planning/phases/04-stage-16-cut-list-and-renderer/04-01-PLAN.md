<objective>
Build the renderer as one thin, complete path first: a two-shot cut list over generated clips passes `check`, is built one shot at a time, joined and encoded once into an MP4 that fits under the send-back limit, and comes with a proof sheet, in both shapes. Moves, photos, music, the touch-up, the cover still and the full rulebook come in plans 03 to 08 and slot into what this plan builds without changing its shape.

Purpose: every later plan of this stage extends these modules, so the command line, the module names, the scratch-folder rule, the frame arithmetic and the output names are fixed here.

2. v2r/render/plan.py (pure: no files, no FFmpeg; every setting read inside the functions at call time, because tests monkeypatch them). Module docstring: this is the arithmetic `check` and `render` share so they can never disagree. `frames(seconds, fps=None)` = math.floor(round(seconds x fps, 6) + 0.5), fps defaulting to settings.OUTPUT_FPS (D-01: nearest frame, half up; the 6-decimal rounding removes float noise). `clip_frames(seconds, fps=None)` = math.floor(round(seconds x fps, 6) + 0.001): the whole frames a working copy holds. `segment_frames(segment)` = (frames(from), frames(to - from)). `even(x)` = 2 x floor(x / 2 + 0.5) (half up, never Python's banker's rounding) and `even_floor(x)` = 2 x floor(x / 2). `fill_region(source_size, canvas_size, focus_x=0.5, focus_y=0.5)`: k = max(CW / SW, CH / SH); region Rw = CW / k, Rh = CH / k; crop_w = min(even_floor(SW), even(Rw)), crop_h = min(even_floor(SH), even(Rh)); crop_x = even_floor(clamp(focus_x x SW - crop_w / 2, 0, SW - crop_w)) and crop_y likewise with focus_y; share = (Rw x Rh) / (SW x SH); focus in canvas pixels = ((focus_x x SW - crop_x) x CW / crop_w, (focus_y x SH - crop_y) x CH / crop_h); returns {"crop": [crop_w, crop_h, crop_x, crop_y], "share": share, "focus": [fx, fy]}. The focus point is the spot in the source that sits at the frame's centre when it can (D-05); on an axis the clip already fills the clamp makes it move nothing, silently. `plan(cutlist, manifest)` assumes a list that passed check and returns a dict: `shape` (from `check.shape_of(canvas)`, see 3), `canvas` [CW, CH], `fps`, `segments` (one dict per list segment, in list order, D-13: `number` 1-based, `clip` letter, `kind` from the manifest, `working` the working copy's file name, `photo` the manifest's photo file name or None, `source_size` the working copy's size, `start_frame`, `frames`, `reel_start` (the running sum of earlier segments' frames), `crop`, `share`, `focus` from fill_region over source_size with the segment's focus_x and focus_y (default 0.5), `move` (the segment's move, default "none"), `window_start` and `window_end` (both [0, 0, CW, CH] in this task; plan 04 computes moves), `sound` ("keep" or "off"), `touch_up` (the list's `look.touch_up` record for the letter, or None)), `total_frames`, `seconds` (= total_frames / fps) and `sound_block` (the list's `sound` object, or {}).

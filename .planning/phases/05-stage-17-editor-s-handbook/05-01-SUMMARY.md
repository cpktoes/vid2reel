# Phase 5 Plan 01: --work on normalize and look Summary

`normalize` and `look` now take `--work FOLDER`, the same option `check`, `match` and `render` already had, so each rehearsal set can go to its own folder and sit side by side.

## What changed (plain English)

Before this, `normalize` and `look` always used the one `work/` folder, so a second rehearsal would wipe the first. Now you can write `--work work/<set>` and that set gets its own folder. Leaving the option out behaves exactly as before: `work/` stays the default. The phone never uses the option and the handbook does not mention it. Nothing about how video is processed changed, and nothing in the code chooses a shot, a length or a move; it only passes a folder name through. So this plan alone needs no phone test.

Details:
- `normalize --work FOLDER` works before or after the list of files. It clears only that folder's last job, as `work/` is cleared today. A file you attached that already sits inside the folder is left alone, with the sentence normalize already had.
- `look --work FOLDER` works the same as `look FOLDER`. If you name a folder both ways and the two differ, look prints one sentence starting `v2r look:` and stops, writing nothing. The same folder named both ways works.
- README.md now says all five working commands take `--work FOLDER`, a Mac convenience for rehearsals.

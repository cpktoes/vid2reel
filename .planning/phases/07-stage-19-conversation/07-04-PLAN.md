## Plain English for the user

This is the follow-up the guide worries about most: "a bit shorter". The chat's Claude picks which shots to trim, weakest first, because only it has seen the stills. revise does the arithmetic. Each named shot loses frames from its end, so every shot still starts on the same picture, the opener included. They go down to the recipe's shortest (one and a half seconds for Lively); then the rest is shared evenly across the other shots. The reel lands exactly on the length asked, to the frame. Whole shots go only when every shot is already at its shortest, and only shots Claude named, never the first. "Longer" does the reverse: it lets named shots run on, never past the end of their clip and never into footage the next shot shows. If it can't get all the way, it says how far it got. Watch for this on the phone: after "shorter", the reel should open on the very same picture as before.

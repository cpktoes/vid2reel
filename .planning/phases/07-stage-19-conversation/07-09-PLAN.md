## Plain English for the user

This is the test that decides whether the stage can merge: the whole conversation, on your phone, inside a Project with a Reel style section. You attach a few clips and type one sentence. Check that the first reply is only the questions. After you answer, one line with a time estimate, then quiet until the reel. Then "shorter": the new reel must open on exactly the same picture at 0:00, with the same shots, each a little shorter. That is the guide's big worry, so watch the first second closely. Then "mute it": silence from start to end, same length. If something is wrong, the fix goes through the same checks, your names scan and your word on uploading (plan 08) before you test again, because the phone only sees what is on GitHub. Afterwards Claude writes the result into the records, lists every way this stage differs from the guide, and scans the record commits. They go to GitHub with the merge, after your own names check over them.
